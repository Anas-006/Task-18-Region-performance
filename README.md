Task 18 – Region Performance

Objective

To compare sales and profit across different regions using Excel and Power BI.

Tools Used

- Microsoft Excel
- Power BI

Approach

- Grouped the Superstore data by Region.
- Calculated total Sales for each region using SUMIF.
- Calculated total Profit for each region using SUMIF.
- Ranked the regions based on total Sales.
- Created a bar chart to compare regional performance.
- Created Power BI visuals for Sales by Region and Profit by Region.

Outcome

The analysis provides a clear comparison of Sales and Profit across regions and helps identify differences in regional performance.

Deliverables

- Region summary table
- Region ranking
- Sales and Profit bar chart
- Power BI visualizations
- Rollback evidence
